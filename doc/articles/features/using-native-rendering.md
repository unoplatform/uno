# The Native Renderer

> [!IMPORTANT]
> The native renderer was **removed in Uno Platform 7.0** — [Skia](xref:uno.features.renderer.skia) is now the only renderer on every target, including Android, iOS, and WebAssembly. It was available in Uno Platform 6.x and earlier.

- To learn how Uno Platform renders the UI, see [The Skia Renderer](xref:uno.features.renderer.skia).
- To use a platform control in your app, see [Embedding Native Elements in Skia Apps](xref:Uno.Skia.Embedding.Native).
- To upgrade an app that used the native renderer, see [Migrating to Uno Platform 7.0](xref:Uno.Development.MigratingToUno7).
