# Uno Platform

[Uno Platform](https://platform.uno) is an open-source developer platform for building single-codebase .NET applications with C# and XAML that run on Web, Desktop, Mobile, and Embedded systems. It implements the WinUI 3 API surface and renders with Skia across platforms, so your UI looks and behaves the same everywhere.

## Getting started

This package is part of the Uno Platform framework. Most apps don't reference it directly: the [Uno.Sdk](https://www.nuget.org/packages/Uno.Sdk) brings in the right packages based on the target platforms and the `UnoFeatures` your project enables.

To create a new app, follow the [Get Started guide](https://aka.platform.uno/get-started).
